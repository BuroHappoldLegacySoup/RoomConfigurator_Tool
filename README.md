# RoomConfigurator_Tool

This repository can be used to create brand new Zero-code tools :rocket:

- Just click on the green button above "Use this template" :point_up_2: . Call the new repo with the name of your software followed by `_Tool`, e.g. "MySoftware_Tool". If you want to develop outside of a repository, you can download the code by clicking "Code" and then saving it as zip.
- Go in your repository or unzipped folder, double click the `RenameToolFiles.bat` file. When asked, insert the name of your software, e.g. "MySoftware". All the files and folder will be renamed accordingly.
- Start developing! :rocket:
